# 监测井封填见证台

监测井封填见证台是一套面向地下水监测井退役作业的本地浏览器应用。它将井况基线、分层封填方案、逐段施工证据、偏差纠正、完整性验证、独立见证和只读归档串成一条可追溯流程。服务不依赖外部系统，业务数据、幂等结果、规范化实体投影、追加式审计链和归档都保存在 SQLite 中。

状态按以下顺序受控迁移：

`draft` → `baseline_locked` → `sealing` → `verification` → `released` → `archived`

施工门禁失败或见证退回时会进入 `held`。多个偏差按严重级别逐项处置，只有最后一个开放偏差合格关闭后才恢复到 `sealing`。归档后的业务事实不可再变更。

工作台支持按井号、场地、责任人、状态和创建时间检索，并以稳定游标翻页。方案冻结前可只读核算理论体积、分层差异、材料批次汇总和全部阻断问题；施工入口既兼容单条检查点，也支持最多 25 条连续检查点的原子批量登记。个案详情即时展示分层与深度进度、材料偏差、证据缺口、验证预检和独立见证清单。

草稿阶段可通过工作台基线表单或 `PATCH /api/cases/{id}/baseline` 修订井号、场地、坐标、井深、套管和责任人。请求携带 `request_id`、`expected_revision` 与 `actor`，成功后生成基线修订审计事件；基线冻结后禁止修改。偏差详情旁提供只读 `GET /api/cases/{id}/deviations/summary` 统计，可按 `detected_from`、`detected_to`、`open`（以及类别、严重级别）筛选，返回稳定排序的分组计数、处置耗时和最近复验结果。

## 构建与运行

要求 Go 1.22 或更高版本。

```text
go build ./cmd/wellseal
go run ./cmd/wellseal
```

默认监听 `127.0.0.1:19091`，默认数据库为当前目录的 `wellseal.db`。打开 `http://127.0.0.1:19091/` 即可使用工作台。可用参数指定回环监听地址和数据库：

```text
go run ./cmd/wellseal -addr=127.0.0.1:19123 -db=./data/wellseal.db
```

未传 `-addr` 时，也可通过 `PORT` 环境变量指定端口；例如 `PORT=19123` 会绑定 `127.0.0.1:19123`。服务拒绝非回环监听地址，避免意外暴露业务数据。

## 测试与自检

运行全部单元与持久化回归测试：

```text
go test ./...
```

运行有界真实 HTTP 自检：

```text
go run ./cmd/wellseal -self-check -addr=127.0.0.1:19091
```

自检使用临时 SQLite 数据库和真实回环 HTTP 服务，依次完成建档、基线冻结、方案锁定、施工开启、不合格材料触发暂停、纠正复验、合格检查点、完整性验证、独立放行和归档下载，然后主动关闭服务并删除临时数据。

## 数据与审计约束

- 所有写请求携带 `request_id` 和 `expected_revision`。相同请求可安全重放，不同载荷复用同一 `request_id` 会被拒绝。
- SQLite 短事务同时比较修订号、保存业务事实、更新实体投影并追加带前序 SHA-256 摘要的审计事件。
- 检查点批次校验连续序号、方案深度、施工阶段、材料批次、实际用量容差、分层必需证据类型和最终区间终孔标高；成功批次只递增一次修订并追加一个事件，失败批次不写入任何施工检查点。
- 完整性验证预检与正式验证共用逐层报告规则，正式请求同时校验修订号和预检摘要。
- 独立见证人不得参与方案编制、复核、施工记录或偏差关闭；放行必须确认全部审阅清单项。放行后立即生成确定性 JSON 归档并进入 `archived`。
- 归档查看和下载都会重新校验载荷、清单摘要、验证摘要、见证决定、证据清单和完整事件链。下载支持基于 `manifest_digest` 的 `ETag` / `If-None-Match` 条件请求。

## 主要目录

- `cmd/wellseal`：配置、依赖装配、服务生命周期与真实 HTTP 自检。
- `internal/domain`：领域实体、状态、门禁与稳定摘要。
- `internal/application`：全部业务用例和事务编排。
- `internal/store`：SQLite 事务、实体投影、幂等、审计链和归档读取。
- `internal/archive`：确定性 JSON 归档生成与校验。
- `internal/web`：同源 JSON API、安全中间件和原生浏览器工作台。
